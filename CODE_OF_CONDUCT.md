# Code of Conduct

## Our Pledge

We pledge to make participation in this project welcoming and free from harassment for everyone, regardless of background, identity, experience, or ability.

## Our Standards

Treat others with respect, welcome different perspectives, give constructive feedback, and take responsibility for mistakes. Harassment, threats, discriminatory language, personal attacks, and sharing private information without consent are unacceptable.

## Enforcement Responsibilities

Project maintainers clarify these standards, review reports fairly, and may remove content or restrict participation when needed. Maintainers should explain moderation decisions where doing so protects the people involved.

## Scope

This code applies to project spaces and to public spaces when someone officially represents the project.

## Enforcement

Report violations to the project maintainers. Use a private channel when a report contains sensitive details. Maintainers will review reports promptly and protect the reporter’s privacy as far as possible.

## Enforcement Guidelines

1. **Correction** — Explain the violation and request a change in behavior.
2. **Warning** — Set clear conditions for continued participation.
3. **Temporary ban** — Suspend participation for a defined period after a serious or repeated violation.
4. **Permanent ban** — End participation after severe misconduct or a pattern of violations.
